# Widescreen

**A Gibberlings Three Mod**  
**Author:** [the_bigg](https://www.gibberlings3.net/profile/426-the-bigg/)  
**Version:** 3.08  

This mod allows classic Infinity Engine games to be played at previously unsupported resolutions (including widescreen and custom resolutions).

## Supported Games

- Baldur's Gate + Tales of the Sword Coast
- Baldur's Gate II: Shadows of Amn (with or without Throne of Bhaal)
- Icewind Dale + Heart of Winter
- Icewind Dale II
- Planescape: Torment

**Not supported:** Enhanced Edition (EE) versions of these games.  
The EE engines already support arbitrary resolutions natively, so this mod is unnecessary (and will fail to install) on EE.

## Compatibility

Compatible with virtually all WeiDU mods.  

- GUI mods for BG2, IWD, and IWD2 should be installed **before** Widescreen.
- BG1 GUI and Ghostdog's PST UI should be installed **after** Widescreen.

See the full readme for details on save game compatibility and other notes.
