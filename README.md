# Widescreen Mod

The Widescreen Mod lets you play supported classic Infinity Engine games
at resolutions they did not originally support.

It supports the original versions of Baldur's Gate with Tales of the Sword
Coast, Baldur's Gate II: Shadows of Amn (with or without Throne of Bhaal),
Icewind Dale with Heart of Winter, Icewind Dale II, and Planescape: Torment.
It is not intended for the Enhanced Editions, which already support
arbitrary resolutions.

For installation, compatibility, and troubleshooting, see the
[official readme](https://gibberlings3.github.io/Documentation/readmes/readme-widescreen.html).
For downloads and project information, see the
[Widescreen Mod page](https://www.gibberlings3.net/mods/tools/widescreen/).
